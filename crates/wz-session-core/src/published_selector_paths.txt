# EVERY FACT THE DECLARED SHAPE HAS PUBLISHED, one a line, and the file only
# grows. A path a selector names is a name a consumer keeps (in a saved
# selector, in the `selector_path` of a document it stored), so a fact once
# here is never taken back:
#
#   <path>\t<kind>            the path is declared, read at that kind
#   <path>\t<kind>\t<word>    the label at that path carries that word
#
# A path is the FIELD's: a record's field stands at `<message>...` alone and at
# `Frame.payload.<message>...` under the Frame that carried it, and is one fact,
# written from the message.
#
# `dissect_schema::tests::every_published_fact_still_holds` holds the shape to
# every line, under the path's CURRENT name (`dissect_schema::RENAMED`), and
# lists the facts the shape declares that are not here yet, to be appended in
# the commit that declares them by `scripts/lib/publish_selector_paths.py
# --append`. A line is never edited or removed (`--check <ref>` refuses a line
# a ref published and this file lost): a field that moves is renamed, and a
# field whose kind changes takes a new name.
#
# First written at field document revision 56, the first to carry
# `selector_path` on every node. A body whose encoding its carrier does not
# fix (`value` of an unnamed extension entry or an `Oam`) is published under
# the encoding's name, `z64` or `zbuf`: under one name it was a path of two
# kinds, which every selector naming it was refused for, so no selector ever
# read it by that name.
