# Census slice S5: runtime infrastructure (rest of wz-runtime-tokio, wz-session-mcu, wz-runtime-coop)

Scope: `crates/wz-runtime-tokio/src/` minus the S4 files, `crates/wz-session-mcu/src/`,
`crates/wz-runtime-coop/src/`; test-only files (`test_fixtures.rs`, `static_tests.rs`) skipped.
`wz-session-mcu` `latest.rs` was skipped here as test-only, which it is not (it is compiled under
`session-slot` + `client-core`); S10 row 85 classifies it (2026-11-20). Line counts are production lines with inline `#[cfg(test)] mod`
blocks removed; they INCLUDE doc comments, which are 40-60 % of most of these files, so read
them as the size of a responsibility, not as code to translate.

SCE references used throughout (read from `origin/main` of the scxml-core-engine repository):

- `[cat:<kind>]` = `kind-catalog.json` entry for that kind.
- `[F4.3]` = `SCE_FORGE.md` §4.3 lookup: keys are numeric or `enum:<alias>`, no text key.
- `[F3.4x]` = `SCE_FORGE.md` §3.4 "External Function References": an unmatched call becomes a
  forward-declared user function (value types must still be expressible).
- `[F4.12L]` = `SCE_FORGE.md` §4.12 "Bounded list" / "Lists of records": `list<T>` of numbers or
  records, read-only parameter views, and "an algorithm whose signature takes or returns a list
  cannot be called from another algorithm".
- `[SUB-LV]` = `docs/SCE_ACCEPTED_SUBSET.md` "List variables" (line 5809ff): a `sce-static`
  statechart list supports `<sce:append>`, `<sce:clear>`, `len()`, index READ, `<foreach>`;
  "An element is read and never written", whole-list assignment refused.
- `[SUB-BC]` = `docs/SCE_ACCEPTED_SUBSET.md` line 7986ff: "a `sce-static` statechart has no
  variable of [bounded-collection] kind", and an algorithm looping over one is refused.
- `[SUB-TT]` = `docs/SCE_ACCEPTED_SUBSET.md` line 768ff: text-template holes are `string[B]`,
  fixed-width integer or closed enum; "a list" / "a record" hole is refused.
- `[SUB-ENC]` = `docs/SCE_ACCEPTED_SUBSET.md` line 4691: codec `sce:encoding` values are
  `cbor` and `content-line` only (no JSON).
- `[SUB-PAR]` = `docs/SCE_ACCEPTED_SUBSET.md` line 39: `<parallel>` is a core construct.
- `[RFC5I]` = `docs/rfc-sce-protocol-synthesis.md` §5.I (`sce:extern`): whitelist is atomics /
  fences / MMIO intrinsics, not crypto or allocators.
- `[SCE-model]` = `sce-build/src/forge/model.rs` `LinkModel` (classes udp/tcp/serial/websocket/
  raw-eth, framer, backpressure drop/block/signal-event, rx/tx/stage pool refs),
  `WorkerModel` (link_rx + inbox queue_ref + optional outbox), `BufferPoolModel`,
  `QueueModel`.

New gap codes defined by this slice (beside T/M/H/C/A/F/P/O):

- **J** — a JSON / JSON5 document as data: parsing one into a tree, merging into one, or
  rendering one with a variable number of rows. No codec encoding is JSON `[SUB-ENC]`, and a
  text-template has no list or record hole `[SUB-TT]`.
- **L** — a table keyed by TEXT (a config key path, a scheme name). `lookup` keys are numeric or
  enum only `[F4.3]`; the workaround (an enum of the names plus an algorithm of string
  compares to reach it) is possible but doubles the table.

## Summary

- lines by class (approx., doc comments included): A=870, K=11,800, G=24,180, S=30,100,
  D=980, X=9,750 (of about 77,600). S and X dominate wz-runtime-tokio; most G lines are
  config/JSON (rows 2-4, 7-13, 15: about 9,800).
- gaps found:
  - J (new; 10 rows: 2, 4, 9, 11, 12, 13, 15, 18, M8, M9): no JSON codec encoding and no list hole in text-template.
  - L (new; 4 rows: 3, 4, 7, 10): lookup keys are numeric or enum, never text.
  - M (14 rows: 8, 17, 18, 29, 31, 41, 53, 57, 61, M2, M4, M5, M16, M17): a statechart cannot hold a bounded-collection, and its list variables cannot update or remove an element.
  - H (11 rows: 4, 7, 8, 11, 12, 22, 26, 30, 48, 62, M8): text, lists and paths of unbounded size.
  - T (6 rows: 11, 13, 15, 28, 29, 54): recursive data, the HAMT, the keyexpr trie and the AllocPolicy tree.
  - C (6 rows: 28, 31, 46, 53, 55, 56): atomics protocols across processes, a lock-shared store, and an SN minted together with its enqueue.
  - A (rows 22, M16): many requests in flight, each with its own deadline.
  - F (row 30): RSA over unbounded bytes.
  - P (row C4): the worker kind's inbox would add a copy to rx-in-place dispatch.
- deliberate fixes to carry: rows 3, 4, 7, 11, 13, 15, 17, 18, 19, 22, 23, 35, 37, 38, 43, 46,
  47, 48, 54, 55, 59, 60, 61, 63, 65, M2, M3, M4, M5, M9, M13, M17, C2, C4.
- doubts:
  - The link kind is unproven in wz. `sources/links/lwip_udp_*.scxml` exist, but nothing generates them and nothing uses them (C5).
  - `multicast_glue.rs:14` claims SCE has no `<parallel>`, but `[SUB-PAR]` lists it as a core construct. That premise is stale.
  - M6, M10 and M14 are K with stated doubts.
  - Rows 35 and 45 are S, but they encode measured performance properties (P) that any generated replacement must keep.
