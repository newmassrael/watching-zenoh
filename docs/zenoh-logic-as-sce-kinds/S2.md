# Census slice S2: wz-session-core data plane (query/reply, pub/sub, declarations, keyexpr)

Scope: the 74 files of the brief's S2 list under `crates/wz-session-core/src/` (two of them,
`declare/cross_tests.rs` and `declare/lent_tests.rs`, are test files). The production size is
about 21,500 lines of code. That count leaves out blank lines, comment lines and every
`#[cfg(... test ...)]` module. Every path below is relative to `crates/wz-session-core/src/`
unless it says otherwise.

Yardstick: `kind-catalog.json` and SCE `origin/main` `SCE_FORGE.md` (cited as FORGE) and
`docs/SCE_ACCEPTED_SUBSET.md` (cited as SUBSET).

SCE facts the rows rely on, read directly:
- **algorithm** (FORGE §4.12, line 2152 onward). Bounded `while`/`foreach` loops, `bytes` and
  `string` parameters, `len` and `x[i]`, and `list<T>`/`list<record>` working buffers. A buffer
  is append-only: "no index writes (`buf[i] = x` remains rejected)" (FORGE l.2158). A list's
  `capacity` is a hard bound on Rust even under `alloc` (FORGE §4.12 tables). An algorithm whose
  signature takes or returns a list "cannot be called from another algorithm" (FORGE l.2240).
  It may return `enum:<alias>` and `record:<alias>`. A record's string field needs a
  `sce:max-size`.
- **bounded-collection**. A fixed-capacity typed table, "a slot table addressed by handles, with
  insert/remove/get" (FORGE l.3117). An algorithm may `foreach` over it. A `sce-static`
  statechart "has no variable of that kind" (SUBSET l.7986-7995).
- **statechart lists** (SUBSET l.5809-5845). A `list<T>`/`list<record>` variable is written by
  exactly two statements, `<sce:append>` and `<sce:clear>`. An element is read-only. No other
  write and no removal exists.
- **many deadlines in one machine**. A delayed `<send>` per wait, with a computed or generated
  id and `<cancel sendidexpr>` (SUBSET l.4174-4180, l.4305-4310). So per-request deadlines are
  expressible. What is not expressible is the keyed table behind them (gap M).
- **lookup** (FORGE §4.3). Numeric or enum keys, a string or numeric output, linear search.
- **External functions** (FORGE §3.4 "External Function References"). A call to an undeclared
  name becomes a host forward declaration. A `<sce:helper>` declares a host function too
  (catalog `procedure` example). There is no `sce:extern` in the SUBSET; RFC §5.I limits it to
  atomics, fences and cache intrinsics.
- **codec** derives presence flags and group gates from the value: ADR 0065 R4a/R4b
  (FORGE l.1048-1050).

## Summary

- **Lines by class** (approximate code lines, excluding blank lines, comment lines and test
  modules; total about 21.5k): A=0, K=7,006, G=9,049, S=1,662, D=463, X=3,368.
  - A=0 is a finding in itself: no SCE algorithm or statechart generated into `out/` is
    called from this slice.
  - Only the codecs (`wz_codecs`) are generated, and the builders and lent writers use them.
  - Keyexpr matching is not SCE. `sources/algorithms/keyexpr_{intersect,includes}.scxml` are
    v1 uint32 id equality, nothing is generated from them, and nothing calls them. The
    wildcard matcher is hand-written (row 1). It is K, using a bottom-up DP because algorithm
    buffers are append-only.
- **Gaps:**
  - **M (18 rows, 5,026 lines; rows 7-10, 14, 17, 21, 27, 30-32, 34, 37, 39, 41-44).** A
    runtime-keyed table that a machine owns and mutates (bind, replace or unbind by id, zid,
    interest id or keyexpr, with a counted refusal when full).
    - A bounded-collection has handles, not keys, and no statechart can hold one.
    - Statechart lists only append and clear.
    - Per-request deadlines are expressible as delayed `<send>` plus `<cancel sendidexpr>`,
      so the earlier A gap reduces to M.
