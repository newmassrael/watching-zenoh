# Census slice S1: wz-session-core — transport, links, scouting, multicast, session lifecycle

Scope: the S1 file list in `crates/wz-session-core/src/` (116 files) plus
`sources/session/*.scxml` and `sources/network/*.scxml`. Paths below without a
directory are in `crates/wz-session-core/src/`. "Lines" counts production
Rust lines, `#[cfg(test)]` modules removed, comments and docs included (this
crate is doc-heavy: code-only is roughly half). For class A rows the number is
SCXML lines and the hand-written Rust is 0 unless stated. The three test-only
parity modules (`transport_header_parity.rs`, `transport_message_parity.rs`,
`scouting_message_parity.rs`, 1084 lines, `#[cfg(all(test, ..))]` at
`lib.rs:1076-1106`) are excluded. `session_actions.rs` (16766 lines, one
`SessionLinkActions` impl) is split by responsibility; its splits are by line
range and approximate.

Yardstick: `kind-catalog.json` (generator `d44b0fb8ae8c`), SCE `origin/main`
`SCE_FORGE.md` (cited `forge:<line>`) and `docs/SCE_ACCEPTED_SUBSET.md` (cited
`subset:<line>`), wz `docs/rfc-sce-protocol-synthesis.md` (cited `RFC §`).
Read-only; nothing was built or run.

Gap codes used beyond the brief's (defined in the Summary): **W** (call a
codec from a statechart/algorithm), **R** (record/list element holding bytes or
a nested list), **N** (bounded pool of statechart instances routed by key).
