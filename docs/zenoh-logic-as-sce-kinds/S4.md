# Census slice S4: wz-runtime-tokio router, routing and session API logic, plus wz-routing-graph

Read at wz `main` `d8f187dddc` (working tree, `vendor/sce` modified, not read) and SCE `origin/main`.
Nothing was built or run. Read-only on both repositories.

Conventions used in the table:

- `rt/` = `crates/wz-runtime-tokio/src/`, `rg/` = `crates/wz-routing-graph/src/` (repo-relative prefixes).
- **Lines** are production lines (file lines minus every `#[cfg(test)]` / `#[cfg(all(test, …))]`
  module and the `*_tests.rs` / `session/tests.rs` files), comments and blank lines included. About
  45 % of them are doc comments. A row that spans part of a large file gives an estimate from the
  line ranges cited. The slice totals 75,708 such lines (42,484 non-blank non-comment).
- SCE sources: `CAT <kind>` = the kind's entry in `kind-catalog.json`; `FORGE:n` = `SCE_FORGE.md`
  at SCE `origin/main`, line n; `SUB:n` = `docs/SCE_ACCEPTED_SUBSET.md` at `origin/main`, line n;
  `RFC:n` = `docs/rfc-sce-protocol-synthesis.md` (wz) line n.
- SCE facts every G row leans on, read once here so each row can cite them briefly:
  - **(f1)** A record's fields are fixed-width numbers, `bool`, `enum:` or bounded `string`; a `bytes`
    field is refused (FORGE:2269). A union case that holds a list, record or union is refused
    (FORGE:2333-2340). No element type holds a collection.
  - **(f2)** An algorithm's `list<T>` / `list<record:R>` parameter is a read-only host view, and an
    algorithm that takes or returns a list cannot be called from another algorithm (FORGE:2237-2241, 2303).
  - **(f3)** A `sce-static` statechart may hold a bounded `list<record:R>` (`sce:capacity`), append a
    record by name and walk it with `<foreach>` (SUB:5910-5930). Nothing is said of removal by key.
  - **(f4)** A `bounded-collection` is generated on every backend, but "a `sce-static` statechart has
    no variable of that kind" (SUB:7986-7995); RFC §5.L's `index-by` / `find_by_index` (RFC:2540-2610)
    is the design, and the catalog note says only that it "names its element type by reference".
  - **(f5)** A lookup keyed by a text is refused (SUB:6016).
  - **(f6)** No `sce:extern` exists in `SCE_FORGE.md` or the subset (grep: zero hits); RFC §5.I
    (RFC:1691) is a proposal. A statechart reaches the host through `<sce:action>` effects (SUB:2780)
    and a host-run `<invoke>` whose typed result returns as `done.invoke.<id>` (SUB:3097-3125); an
    algorithm reaches no host function. Tree data is deferred (RFC:1677, §5.H).
  - **(f7)** `queue` names its element by reference, states storage (bounded / segmented / intrusive),
    cardinality and progress, and "names no algorithm and no memory ordering" (CAT queue notes);
    `timer` is periodic only (CAT timer, FORGE:1984); a one-shot deadline is a delayed `<send>` in a
    statechart (CAT statechart distinct_from).
  - **(f8)** The keyexpr matcher the router calls (`wz_session_core::keyexpr_match::
    keyexpr_intersects_target`, another slice) is hand-written. wz's generated
    `sources/algorithms/keyexpr_intersect.scxml` / `keyexpr_includes.scxml` compare two `uint32` ids
    (`keyexpr_intersect.scxml:30-36`); no wildcard matching is generated today.

## Summary

- **Lines by class** (production lines, comments included; rows sum to 75,871 against 75,708
  measured, the difference being range estimates): A = 3,513; K = 5,352; G = 46,356; S = 6,609;
  D = 4,610; X = 9,431. G is 61 % of the slice. wz-routing-graph alone (rows 15 part, 35-43):
  K 768, G ≈ 2,090, D 100, X 290.
- **Gaps found** (rows; a G row may carry several codes):
  - **M** (map keyed by a runtime value) — 34 rows: 3, 4, 6-11, 13-16, 18-20, 22-26, 31, 32, 37, 51,
    53, 55, 57, 58, 61, 70-73, 88. `bounded-collection` does not cover it: no `sce-static` statechart
    can hold one (SUB:7986-7995), its `index-by` lookup is RFC design only (RFC:2540-2610), a text key
    is refused (SUB:6016), and the router's capacities are not build-time numbers (2,048 client faces
    measured).
  - **C** (shared state across contexts) — 20 rows: 15, 19-22, 27-31, 48, 51, 52, 54, 59, 60, 89-92.
    The missing element is a shared-state model that is not a FIFO: a reader-writer lock with a
    bounded writer-first read, read-copy-update with a grace period, atomic counters and epochs,
    per-lock order rules. `queue` / `broadcast-log` name no algorithm and no ordering (CAT queue);
    `sce:extern` atomics are a proposal (RFC:1691).
  - **A** (asynchrony) — 14 rows: 11, 18-21, 29, 53, 54, 57, 69-71, 87, 88. A table of in-flight
    requests, each awaiting several replies with its own deadline, plus executor `select!` over a
    runtime-sized set of futures. `procedure` is one run, `timer` is periodic only.
  - **N** (new code: a general graph — nodes and edges with stable indices, a runtime number of them,
    and algorithms over it: shortest paths per root, reachability, GC of detached nodes) — 7 rows: 5,
    14, 32, 37-40. Neither a tree (T) nor a keyed map (M) expresses it.
  - **L** (new code: an element that holds a collection — a record with lists, a map whose values are
    maps) — 8 rows: 3, 7, 8, 13, 48, 49, 60, 72, and the hat structure throughout. FORGE:2269 and
    FORGE:2333-2340 keep records and union cases to scalars and bounded strings.
  - **H** — 10 rows: 6, 29, 37-40, 51, 59, 65, 90 (payloads, lists built from the graph, locator text).
  - **T** — 3 rows: 9, 10, 12 (keyexpr trie; RFC §5.H deferred).
  - **F** — 2 rows: 38, 39 (petgraph Bellman-Ford; fixed-key SipHash for the edge jitter, which must
    stay bit-identical to zenohd's). An algorithm reaches no host function; a host-run invoke answers
    by event (SUB:3097).
  - **P** — 7 rows: 4, 12, 15, 27, 52, 69, 90 (measured figures cited in each row; row 8's inline
    region values is P as well).
- **Deliberate fixes a migration must carry**: 2, 5-11, 14-16, 18-24, 26-31, 37, 38, 40, 53, 54, 56,
  59, 65, 69, 70, 77, 82, 84, 87, 89-92. The ordering / race / table-sharing ones concentrate in 19-22 and 27-29
  (last-out final gate, bounded self-echo, sends owed until the lock is released, deregister grace
  period, batched writes that end before a read, writer-first after 10 ms, RCU publish) and in 89-90
  (drain-not-discard, control fence behind staged data).
- **Doubts and things outside the classes**:
  - Row 2, 17, 47, 56, 75 are K only if the host hands them a list it computed from G state; the
    decision is expressible, its inputs are not.
  - Every keyexpr match in this slice goes through a hand-written matcher (f8); wz's generated
    keyexpr algorithms compare ids. That gap belongs to the slice that owns `keyexpr_match`.
  - A rows (66, 68, 79, 80) count the hand-written binding lines around a generated machine.
  - The router's Cargo features (`routing-token-tables`, `router-multicast-faces`, …) are a
    `feature-model` (K) concern not given rows of their own.
  - Line counts within `router_forward.rs`, `session/mod.rs` and `accept_loop.rs` are estimates
    from cited ranges; per-class totals are within a few hundred lines.
