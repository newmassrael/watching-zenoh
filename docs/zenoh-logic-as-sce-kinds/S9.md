# Census slice S9: MCU and hosted runtimes, links, network stacks and time

Scope: the `src/` of `wz-session-lwip`, `wz-link-lwip`, `wz-mcu-session-acceptor`,
`wz-mcu-multicast-e2e`, `wz-mcu-clock`, `wz-runtime-core`, `wz-runtime-posix`,
`wz-runtime-zephyr`, `wz-runtime-freertos`, `wz-host-net`, `wz-packet-socket`, `wz-tls-record`,
`wz-tls-mbedtls`, `wz-tls-pem`, `wz-oa-tc6`, `wz-eth-lan865x`, `wz-eth-mac-cyt4bf`,
`wz-eth-mac-lan9118`, `wz-spi-scb`, `wz-node-time`, `wz-codecs` and `wz-statechart-bridge`. Line
counts are production lines: inline `#[cfg(test)] mod` blocks are removed, and so are the files
that only a `#[cfg(test)] mod x;` reaches (`wz-session-lwip` `two_session_tests.rs` and
`tx_pool_session_tests.rs`; `wz-host-net` `link_interfaces/{tests,expansion,adapter_table_reading,scouting_interface_reading}.rs`
and `multicast/tests.rs`; `wz-eth-lan865x` `model.rs` and `tests.rs`; the `tests.rs` of
`wz-tls-mbedtls`, `wz-oa-tc6`, `wz-eth-mac-cyt4bf`, `wz-spi-scb` and `wz-node-time`), the
`#[cfg(any(test, feature = "fixtures"))]` file `wz-tls-record/src/quic/fixture.rs`, and the
`#[cfg(any(test, feature = "test-support"))]` harness in `wz-link-lwip/src/lib.rs`. Comments and
doc comments are counted, as in S5; they are 40-60 % of most of these files, so read a count as
the size of a responsibility, not as code to translate. Counted by a script that removes the
`#[cfg(test)]` blocks by brace depth; a row's count is the sum of the line ranges it names, to a
few lines.

How a driver is read here: a register access, a DMA descriptor, a socket or an OS call is S; a
sequence or a state machine a driver runs over those accesses (a chip's bring-up, a PHY
negotiation, the OA-TC6 chunk protocol, a link's open with its handshake budget) is a row of its
own and is K or G. Every crate in the scope has rows. Three crates are classified although their
logic is not the node's: `wz-tls-record` is the analyzer's offline TLS 1.3 and QUIC decryption
(`wz-tls-record` depends on `wz-capture`, which the census left out, main doc section 2), and
`wz-mcu-session-acceptor` and `wz-mcu-multicast-e2e` are on-target test scenarios shipped as
libraries; their rows are marked so (rows 17-19 and 42-47).

The 2026-11-19 readings of the catalogue are applied: U4 is answered by a boundary binding (door
bytes to a bound codec to a typed schema event, and a `<send>` of a bound schema to the encoder),
so an SPI exchange or a library step whose outcome a machine branches on is a door raising an
event, and the machine above it is K; U8 is withdrawn as a request, so a lock or an atomic that
guards protocol state is classified by that state, with S for the door, and the note says so.

SCE references (read from `origin/main` of the scxml-core-engine repository, `e7640cec53`):

- `[cat:<kind>]` = the `KindGuide` summary of that kind in `sce-build/src/forge/kind_catalog.rs`
  (statechart `:126`, codec `:253`, procedure `:280`, timer `:382`, algorithm `:425`, link `:446`,
  buffer-pool `:472`, worker `:489`, queue `:536`).
- `[F4.3]` = `SCE_FORGE.md` §4.3 lookup: keys numeric or `enum:<alias>`; a `string` output is
  generated as an enum.
- `[F4.5]` procedure, `[F4.6]` codec, `[F4.7]` validator, `[F4.10]` timer: `SCE_FORGE.md` §4.5,
  §4.6, §4.7, §4.10.
- `[F4.12B]` = `SCE_FORGE.md` §4.12 "Byte-buffer-build": an algorithm reads a `bytes`
  parameter by index and builds one `bytes[N]` output forward-only by `<sce:append>`; no index
  write.
- `[SUB-BYTES]` = `docs/SCE_ACCEPTED_SUBSET.md` "A byte string" (line 5302ff): a statechart
  `bytes` variable has a declared capacity and is assigned, compared and measured; a record's
  `bytes` field is held to its schema's `sce:max-size`; an event payload's `bytes` field is read
  into a variable or a field. This narrows U3 as the catalogue words it ("a `bytes` field is
  refused").
- `[SUB-BC]` = `docs/SCE_ACCEPTED_SUBSET.md` line 8284ff: "a `sce-static` statechart has no
  variable of that kind" (bounded-collection).
- `[ADR0108]` = SCE `docs/adr/0108` (Accepted 2026-11-19): `map<K, V>[B]` and `set<K>[B]` in a
  statechart, keys include `string[B]`, `bytes[B]` and records of keys, a full table answers
  `full`. Its "Order of work" marks the grammar, the checker, the Interpreter and Rust as landed
  and C11 (step 6) and algorithm slots (step 7) as not. It is the answer to U1 and U2b; this slice
  keeps those rows G because the C build is the zenoh-pico preset and the C11 lane has not landed.
- `[ADR0086]` / `[ADR0092]` = an event field may hold a bounded list / one of several record
  shapes chosen by a tag (both Accepted).
- `[ADR0095]` = a fixed codec field is bits of the bytes it spans (Accepted 2026-11-09).
- `[ADR0084]` = what reaches an engine from outside enters through one inbox (the door the U8
  reading names).
- `[SCE-link]` = `sce-build/src/forge/model.rs` `LinkClass` (`:5987`: udp, tcp, serial,
  websocket, raw-eth) and `LinkModel` (`:6150`: framer ref, backpressure, inbound/outbound events,
  rx/tx pool refs).
- `[MAIN-4.2]` = main doc section 4.2: a single deadline is a delayed `<send>` on the machine's
  host-owned clock, not a gap.
