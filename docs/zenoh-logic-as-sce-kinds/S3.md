# Census slice S3: wz-session-core, everything not in S1 or S2

Scope: the 49 files of `crates/wz-session-core/src/` left after subtracting the S1 and S2
pattern sets (see "Doubts" for `sink.rs`, which matches neither set's patterns). Production
lines exclude `#[cfg(test)]` / `#[cfg(all(test, ..))]` items, counted by brace matching;
total in slice about 34,320 lines (lib.rs 2,351 of them, 1,482 of which are comment lines).

SCE sources cited: kind catalog (`kind-catalog.json`, cited as "catalog <kind>"),
`SCE_FORGE.md` at `origin/main` (cited "FORGE §n"), `docs/SCE_ACCEPTED_SUBSET.md` at
`origin/main` (cited "SUBSET §n"), wz RFC `docs/rfc-sce-protocol-synthesis.md` (cited "RFC §n"),
and wz `docs/zenoh-as-sce-codec-documents.md` (cited "codec census").

Facts used repeatedly:
- F1. A `sce-static` statechart variable may be a `list<record:..>` bounded by `sce:capacity`
  (FORGE §4.12 "Lists of records", last bullet; SUBSET §2.15).
- F2. A `sce-static` statechart has no variable of kind bounded-collection; an algorithm that
  loops over a bounded-collection import is refused (SUBSET §2.15, end of the Interpreter
  lowering text). bounded-collection's `index-by` exists (RFC §5.L; SUBSET diagnostics
  `collection/index-by-field-missing`), but no statechart can hold such a table.
- F3. An algorithm whose signature takes or returns a list cannot be called from another
  algorithm (FORGE §4.12 "v1 scope — a list crosses only the host boundary").
- F4. `<sce:action>` must be a direct child of a transition / onentry / onexit; nesting inside
  `<if>` / `<foreach>` is refused in v1 (SUBSET §2.11, "v1 acceptance contract"). The host
  answers only whether it performed the action; no value comes back.
- F5. `sce:extern` (RFC §5.I) whitelists atomics, fences, cache maintenance and IRQ control
  only. FORGE §3.4 "External Function References" lets an expression call an undeclared
  function the user supplies (shown for C++), not verified here for algorithm bodies or for
  `bytes` returns.
- F6. timer is periodic only, no one-shot (catalog timer, notes).
